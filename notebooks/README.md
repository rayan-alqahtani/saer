# دفتر مرجعي لهوية السيارة

احتفظنا بالدفتر `saer_identity_reference.ipynb` لأغراض المقارنة البحثية والتحقق من النتائج التاريخية فقط. **هذا ليس دفتر تشغيل Kaggle ولا يشغّل موقع سعّر الحي**. حُذفت دفاتر خادم Kaggle القديمة بعد الانتقال إلى Modal.

## المتطلبات

- افتح الدفتر داخل Jupyter أو VS Code من جذر نسخة المشروع التي تحتوي ملفات الأوزان وميزات التقييم المعتمدة.
- اختر بيئة Python تثبّت الحزم المذكورة في المشروع مثل numpy وscikit-learn وjoblib.
- لا يفترض الدفتر وجود البيانات أو الكاش في المستودع العام: قد يتعذر تشغيل بعض الخلايا دون الأصول البحثية الأصلية.
- توجد داخله إحالة تاريخية إلى مسار Windows محلي `C:\CAR` بوصفه مسارًا احتياطيًا. ليس هذا مسارًا محمولًا، وقد تحتاج إلى تعديل مسار العمل في نسخة خاصة عند إعادة إجراء التقييم.

الدفتر لا يعيد تدريب النموذج ولا يستخرج ميزات صور جديدة؛ بل يعيد حساب بعض المؤشرات من الأصول المخبأة عند توفرها. لا تُعامل هذه المقاييس بوصفها اختبارًا جديدًا للنموذج المنشور.
