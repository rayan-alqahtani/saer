# تشغيل سعّر

## الواجهة

تحتاج Node.js وpnpm. من جذر المشروع:

```powershell
pnpm --dir frontend install --frozen-lockfile
Copy-Item frontend/.env.example frontend/.env.local
pnpm --dir frontend dev
```

افتح `http://127.0.0.1:5173`. يوفر المستودع العام ملفات JSON فارغة للاستعراض والتوصيات والتحليل، ولا يتضمن إعلانات أو صورًا مأخوذة من مصادر أخرى.

## البناء

```powershell
pnpm --dir frontend build
```

## النماذج

يتطلب تشغيل النماذج خدمة Python مستقلة وملفات المشفرات المعتمدة. توجد الشيفرة والاعتمادات في `backend/` و`hf_backend/`، وقد تحتاج البيئة إلى تنزيل مشفرات عامة إضافية. تحقق من تراخيص الأوزان والملفات قبل إعادة التوزيع. يستخدم الموقع المنشور حاليًا خدمة Modal عبر رابط API افتراضي بالواجهة. ويمكن تغييرها محليًا باستخدام VITE_GRADIO_SPACE_URL أو ?api=. راجع [دليل النشر](DEPLOYMENT.md).

لا تتضمن النسخة العامة سجلات البيانات التي استُخدمت في التدريب؛ لذلك لا يمكن إعادة إنتاج مقاييس التقييم التاريخية من الملفات الحالية وحدها.

## ربط الواجهة بالنماذج

يستخدم frontend/src/config.ts رابط Modal الافتراضي. لتجربة خادم مختلف عيّن VITE_GRADIO_SPACE_URL في frontend/.env.local قبل البناء. يجب السماح بأصل الواجهة في FRONTEND_ORIGINS على الخادم. قد تكون هناك قيمة قديمة للرابط في sessionStorage؛ استخدم نافذة خاصة عند فحص الربط الافتراضي.

## حماية البيانات

لا ترفع مجلد `data/` أو صور الإعلانات أو قواعد بيانات أو ملفات اعتماد شخصية. راجع [سياسة البيانات](DATA_POLICY.md) قبل إضافة أي ملفات جديدة. قد تحتوي الإصدارات القديمة أو النشرات المنفصلة على نسخ تحتاج معالجة مستقلة.
