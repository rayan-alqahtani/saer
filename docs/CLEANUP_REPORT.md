# مراجعة المستودع وتنظيف البيانات العامة

تاريخ المراجعة: 6 نوفمبر 2026.

## نطاق العمل

جرت جردة كاملة لمسارات الملفات المتتبعة في شجرة Git، مع مراجعة ملفات تشغيل وتوثيق واختبارات مختارة، وتحديث المراجع التي ثبت ارتباطها بمصدر بيانات الإعلانات السابق. تمت التغييرات أولًا في فرع مستقل.

## ملفات البيانات

- أزيلت `data/processed/listings.csv` و`data/processed/images.csv`.
- أزيلت `data/seed/saer.sqlite`.
- أزيلت صورة الإعلان الأصلية من `frontend/public/demo/img/`.
- استُبدلت ملفات JSON العامة للإعلانات والتوصيات والتحليل بمحتوى فارغ متسق مع واجهات القراءة، مع تحديث بيانات التعريف وخيارات التسعير.
- عُدّل تهيئة قاعدة البيانات المحلية حتى لا تعتمد على استيراد CSV المحذوف.
- عززت قواعد `.gitignore` لمنع إدراج البيانات والصور الخارجية من جديد.

## الواجهة والملفات المحفوظة

- بقي الشعار وعناصر التصميم داخل `frontend/public/ui/` و`frontend/public/assets/`.
- بقيت لقطات الواجهة داخل `docs/assets/` وغلاف README.
- بقيت صور README الأخرى موجودة كما طلب مالك المستودع.
- تبقى لقطات الشاشة أرشيفية؛ قد تظهر بداخلها بيانات كانت معروضة عند التقاطها. لم تُراجع الحقوق البصرية لكل عنصر داخل الصور.

## التوثيق والصيانة

- أزيلت تقارير العمل المرحلية غير اللازمة والتعليمات الداخلية لمساعد البرمجة.
- حُدّث `README.md` و`docs/SETUP.md` وأضيفت `docs/DATA_POLICY.md`.
- حُدّثت أسماء قديمة في أجزاء من كود الواجهة وأدوات معالجة البيانات والاختبارات.
- عُدّلت أداة التعبئة لإزالة اعتمادها على ملف بيان قديم لم يعد موجودًا.
- عُدّلت أداة اختبار التشغيل لإتاحة صورة يختارها المستخدم بدل الاعتماد على صورة العينة المحذوفة.

## نتائج الفحص البنيوي

- عدد الملفات المتتبعة قبل: **312**.
- عدد الملفات المتتبعة بعد: **283**.
- عدد الملفات المحذوفة من شجرة النسخة الجديدة: **30**، مع إضافة ملف سياسة جديد.
- لا توجد ملفات `data/processed/*.csv` أو `data/seed/*.sqlite` أو صورة العينة السابقة في شجرة الفرع.
- ملفات العرض التجريبي الحالية تحتوي **صفر إعلان**؛ وملف التحليل يشير إلى **صفر سجل**.
- روابط الملفات المحلية المذكورة في README: لا توجد روابط مكسورة في الفحص الآلي للمسارات.
- فُحصت أسماء جميع الملفات المتتبعة بحثًا عن أسماء المصدر والعلامة القديمة ومسارات البيانات الأصلية، ولم يظهر تطابق ضمن الأنماط المستخدمة.

## ما لم يُثبت بعد

1. لم تُنفّذ اختبارات Python أو TypeScript أو تشغيل واجهة فعلية داخل هذه المراجعة؛ الفحص البنيوي لا يضمن سلامة كل المسارات بعد حذف البيانات.
2. لا تُزال الملفات من **سجل Git السابق** بمجرد حذفها من أحدث commit. التاريخ القديم لا يزال يتطلب معالجة منفصلة إذا كان الهدف منع الوصول إلى البيانات من الإصدارات السابقة.
3. لا تُحدَّث نسخة Cloudflare Pages تلقائيًا بمجرد تعديل هذا المستودع؛ يلزم تدقيق ونشر مستقلان.
4. ملفات النماذج الثنائية قد تحتوي بيانات وصفية أو تمثيلات مشتقة. لم يُتح تحليلها بشكل موثوق أو التثبت من حقوق إعادة توزيع كل وزن ومكوّن.
5. قد تتضمن لقطات الشاشة القديمة عناصر تخص إعلانات أو مصادر خارجية، رغم الاحتفاظ بها بناءً على الطلب الصريح.

## النتيجة

تمت إزالة الملفات المصدرية الأساسية وبيانات العرض العامة من شجرة الفرع وتحديث الاعتمادات المتأثرة. تظل معالجة تاريخ Git والنسخ المنشورة، والتحقق من حقوق الصور والنماذج، والاختبارات التشغيلية خطوات مستقلة لا يمكن اعتبارها منجزة بمجرد هذا التغيير.
