## سلامة البيانات والملفات

- بقي شعار سعّر وملفات واجهته ومخطط README ودفتر `saer_identity_reference.ipynb` البحثي.
- بقيت قواعد منع بيانات الإعلانات في `.gitignore` و`.github/workflows/public-data-guard.yml`.
- لم تُرفع صور الإعلانات أو قواعد البيانات إلى GitHub أثناء هذا التنظيف.
- **هام:** بيانات العرض والصور الموجودة في موقع Cloudflare قد لا تكون متاحة في GitHub العام. لا تُعِد نشر `frontend/dist` من GitHub فوق نسخة Cloudflare الكاملة دون إعادة دمج أصول النشر المصرح بها.
- لم تُجرَ إعادة نشر Cloudflare أو Modal أثناء هذه المراجعة.
- مسح الأنماط النصية لم يكشف نمط رمز اعتماد صريحًا ضمن الملفات التي شملها المسح، لكن هذا ليس ضمانًا لغياب الأسرار من تاريخ Git أو الملفات الثنائية أو النسخ القديمة.

## نقاط معلقة

1. يحتاج التحقق من البناء واختبارات GitHub Actions إلى متابعة نتائج التشغيل على الفرع أو طلب السحب.
2. لا يمكن إعادة إنتاج النشر الكامل للخادم من هذا المستودع وحده؛ مشروع Modal المحلي و`deploy_modal.py` والأوزان التشغيلية ليست كلها ضمن النسخة العامة.
3. الصور والشعارات والأوزان الثنائية لها مسائل حقوق استخدام وأصول خارجية تحتاج مراجعة مستقلة؛ لم يُثبت فحص ترخيص جميع الأصول.
4. الدفتر البحثي الخاص بالهوية يحتاج كاش النماذج التاريخية، وفيه إحالة قديمة لمسار Windows محلي، موضحة في `notebooks/README.md`.
5. المستودع العام وصور ومعلومات موقع Cloudflare الكامل نسختان بنطاق بيانات مختلف؛ أي تحديث للنشر يحتاج فحصًا مستقلاً قبل استبدال النسخة العامة.
